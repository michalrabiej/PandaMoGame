# Panda Mo: Game Design

## First Prototype

- **Genre:** Calm 2D adventure platformer
- **Main character:** Panda Mo
- **Audience:** Children
- **First level:** Bamboo Garden

## Core Gameplay Loop

1. Explore the environment.
2. Collect bamboo leaves.
3. Help a friendly animal.
4. Return to a safe place.

## Design Principles

- No combat.
- Failure should not cause frustration.

## Controls

- Move
- Jump
- Interact
